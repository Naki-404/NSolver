# Changelog

Все заметные изменения NSolver: Coursera & NetAcad Solver / AutoPass.

## 2.9.0
- **Coursera: ответы по материалам курса.** Субтитры лекций и тексты чтений курса скачиваются один раз (кэш в браузере на две недели, последние 6 курсов); для каждой пачки вопросов в запрос попадают самые подходящие фрагменты (BM25, приоритет модулю теста), около 24 000 символов. Модель отвечает так, как учит курс. Переключатель «Учитывать материалы курса» в карточке Quiz Solver, по умолчанию включён.
- Автосолвер Coursera загружает материалы до первого теста, дальше они берутся из кэша.
- Настройки читаются из хранилища выборочно (кэш материалов не загружается при каждом чтении настроек); разрешение `unlimitedStorage` для кэша.

## 2.8.0
- Coursera, пропуск материалов: **Dialogue** и **Role Play** (Coursera Coach) засчитываются — сессия открывается и сразу завершается через API (проверено на реальном курсе: элемент становится «Completed»).
- Coursera: пропуск сначала читает прогресс курса и трогает только незасчитанные лекции, материалы, диалоги и обсуждения — никаких повторных постов в уже пройденных обсуждениях.
- Coursera, обсуждения: пауза 8 с между ответами; если Coursera отвечает, что лимит постов исчерпан (`FORUM_POST_RATE_LIMIT`), обсуждения останавливаются, и итог объясняет причину. Именно этот лимит не давал засчитывать обсуждения.

## 2.7.2
- Coursera: вопросы с несколькими правильными ответами снова отмечаются полностью. Новые задания Coursera не называют тип вопроса «Checkbox», и такой вопрос считался вопросом с одним ответом. Теперь множественный выбор определяется по типу и полям вопроса, по тексту («Select all that apply», «Choose two», «Выберите все») и по самой странице (checkbox вместо radio).

## 2.7.1
- Coursera: автосолвер видит нынешние тесты Coursera — «Graded Assignment», module challenge, practice quiz (тип `staffGraded`) и «Test your knowledge» (`ungradedAssignment`); раньше он искал только старые типы `exam`/`quiz`. Письменные задания с рубрикой пропускаются.
- Coursera: задания открываются через универсальный адрес `/learn/<курс>/item/<id>`, поэтому подходит любой маршрут (`/assignment-submission/`, `/exam/`, `/quiz/`).

## 2.7.0
- **Автосолвер квизов** (карточка на главной вкладке, кнопка «Пройти весь курс», двойное нажатие для подтверждения, повторное — остановка).
- NetAcad: по каждому модулю засчитывает материалы и проходит все «Check Your Understanding» и квиз модуля (Start → ответы → Submit → подтверждение). Ответы берутся из данных курса; вопросы без них решает модель. Экзамены не открываются. Проверено на реальном CYU 2.2.4 курса Network Security: 7/7, 100%.
- Coursera: по порядку курса проходит оценочные и тренировочные тесты: Start/Resume, решение моделью, Honor Code и имя, отправка, оценка. Работа продолжается после каждой загрузки страницы.
- Пересдача несданного квиза: не пересдавать / 2 / 3 раза (настройка рядом с кнопкой).

## 2.6.0
- **NetAcad: пропуск всего курса.** NSolver сам открывает модули по оглавлению и отмечает материалы через движок курса (модели Adapt): курс из 22 модулей — около минуты вместо ~40 с на один раздел. Проверено на Network Security: 22 модуля, 2163 материала, без ошибок; прогресс сохраняется на сервере.
- Экзамены, финальные тесты, опросы и Packet Tracer Assessment в оглавлении не открываются; вопросы и квизы не трогаются.
- Новый `netacad-main.js` (мир страницы) — доступ к моделям курса; прежний проход по экрану остался запасным.

## 2.5.0
- **NetAcad без скриншотов.** Вопросы и варианты читаются текстом прямо со страницы курса (плеер, фреймы курса, Shadow DOM). Модели уходит только текст: в разы дешевле по токенам.
- **NetAcad: ответы проставляются сами.** Один и несколько вариантов, выпадающие списки, текстовые поля; выбранное подсвечивается. Что не удалось отметить, показывается в карточке с номером и ответом.
- **Пропуск материалов на NetAcad:** видео (плеер video.js с защитой от перемотки) засчитываются как досмотренные, анимации проигрываются, текст прокручивается с уменьшенным масштабом, вкладки и аккордеоны открываются. Проверено на курсе Network Security: раздел 2.5 — 22 из 23 компонентов и оба видео за 40 с.
- Уже отправленные вопросы NetAcad (`is-submitted`) не перезаписываются; экранный текст «1 of 4» и «Complete» не попадает в вопросы.
- Убраны захват экрана и необязательное разрешение `<all_urls>`.

## 2.4.1
- NetAcad: если Chrome / Opera не запустили скрипт на странице курса (`netacad.com/launch`), окно расширения само подключает его к вкладке.
- NetAcad: кнопка **Решить** возвращается, если плеер курса перерисовал страницу.
- Скрипт NetAcad подключается и к фреймам `about:blank` / `srcdoc` внутри курса.
- Понятный статус, если браузер не пускает расширение на страницу NetAcad.

## 2.4.0
- **Cisco NetAcad.** На netacad.com NSolver делает скриншот видимой части вкладки, отправляет его выбранной модели и показывает правильные варианты в карточке на странице. Режим основан на идее [Cisco Netacad Auto-Solver](https://github.com/sanaysarthak/cisco-netacad-autosolver) (Sarthak Sanay, BSD-3-Clause).
- Запуск на NetAcad: плавающая кнопка **Решить**, `Alt+K` (в том числе внутри фреймов курса) или кнопка в окне расширения.
- Скриншоты понимают все четыре API: OctavAPI, Claude API, ChatGPT API, Gemini API. Ключ берётся из настроек, а не из кода.
- Окно расширения на NetAcad показывает карточку Cisco NetAcad: переключатель кнопки на странице и необязательное разрешение «Скриншот без панели».
- Новое название: **NSolver: Coursera & NetAcad Solver / AutoPass**.
