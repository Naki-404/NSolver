## 1. Установка

1. Скачайте проект: на странице репозитория **Code → Download ZIP**, затем распакуйте архив. Если у вас есть git:
   ```bash
   git clone https://github.com/Naki-404/NSolver.git
   ```
2. Откройте страницу расширений браузера:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Яндекс Браузер: `browser://extensions`
   - Opera / Opera GX: `opera://extensions`
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой лежит `manifest.json`.
5. Нажмите значок пазла на панели браузера и закрепите NSolver, чтобы иконка всегда была под рукой.

> Папку после установки не удаляйте и не перемещайте: браузер загружает расширение прямо из неё.

## 2. Обновление

1. Замените файлы в папке расширения новыми (`git pull` или новый ZIP).
2. На странице расширений нажмите **↻ Перезагрузить** у NSolver.
3. Расширение само подключится к уже открытым вкладкам Coursera и NetAcad. Если хоткеи не реагируют, обновите вкладку один раз.

Настройки и ключи при обновлении сохраняются.

## 3. Настройка API

Откройте NSolver → вкладка **Настройки**.

1. **API.** Выберите провайдера: OctavAPI, Claude API, ChatGPT API или Gemini API.
2. **API-ключ.** Вставьте ключ. «Получить ключ ↗» открывает страницу ключей выбранного провайдера.
3. Нажмите **Сохранить** (или Enter). Расширение:
   - сохранит ключ;
   - загрузит полный список моделей из API;
   - отправит короткий тестовый запрос и покажет результат под полем ключа.
4. **Модель.** Выберите модель из списка.
   - **↻** обновляет список вручную. Сам он обновляется раз в 12 часов и при смене API.
   - **✎ Другая модель…** позволяет вписать ID модели, которой нет в списке.

У каждого API свой ключ и своя модель, поэтому между ними можно переключаться без повторного ввода.

### Где взять ключ

| API | Страница ключей |
|---|---|
| OctavAPI | https://octavapi.shop |
| Claude API | https://console.anthropic.com/settings/keys |
| ChatGPT API | https://platform.openai.com/api-keys |
| Gemini API | https://aistudio.google.com/app/apikey |

### Какую модель выбрать

- Простые тесты на знание фактов: быстрые и дешёвые модели (`gpt-6-luna`, `claude-haiku-5-5`, flash-модели Gemini).
- Расчёты, вопросы с подвохом, несколько правильных ответов: более сильные модели (`gpt-6.1-sol`, `claude-opus-5-5`).
- Если сомневаетесь, прогоните пару тестов, где ответы уже известны, на двух моделях и сравните.

## 4. Решение тестов

1. Откройте тест на Coursera и нажмите **Start** или **Resume**: нужна именно открытая попытка.
2. Во вкладке **Главная** статус покажет `Тест найден: N вопр.`
3. Нажмите `Alt+K` на странице или кнопку **Решить тест** в окне расширения.
4. Справа вверху появится уведомление:
   - `Naki: решаю N вопр. с помощью <модель>…`
   - затем `Naki: Готово: ответы на все N вопр.` или `Проставлено X из N… Проверьте вручную вопросы: 3, 7`.
5. Проверьте ответы и отправьте тест сами. **NSolver никогда не нажимает Submit.**

### Авто-решение

Переключатель **Авто-решение** на главной вкладке запускает решение сразу, как только открывается попытка теста. Каждую попытку расширение решает один раз.

### Что поддерживается

| Тип вопроса | Что делает NSolver |
|---|---|
| Один вариант (radio) | выбирает правильный |
| Несколько вариантов (checkbox) | отмечает все правильные и снимает лишние |
| Текстовый ответ, число | вписывает ответ в поле |

Картинки в вопросах передаются модели только как подпись (`alt`), поэтому на вопросах «по картинке» точность ниже.

### Как NSolver повышает точность

- Сверяет номера вариантов с их текстом: если модель ошиблась в номере, берётся вариант по тексту.
- Проверяет, что ответов столько же, сколько вопросов, а у вопроса с одним ответом выбран ровно один вариант. Иначе просит модель исправиться.
- Длинные тесты делит на части по 10 вопросов.
- При ошибках 429 и 5xx повторяет запрос автоматически.

### Материалы курса (Coursera и NetAcad)

Многие тесты проверяют то, чему учит именно этот курс: его определения, списки, цифры и рекомендации. Переключатель **Учитывать материалы курса** (карточка Quiz Solver, по умолчанию включён) добавляет в запрос к модели фрагменты самого курса:

1. **Coursera:** при первом решении теста в курсе NSolver скачивает субтитры всех лекций и тексты всех чтений (обычно 5–15 секунд, прогресс виден в уведомлении). Они хранятся в браузере и скачиваются заново, когда станут старше срока из настройки **Обновлять через, дней** (карточка «База материалов», по умолчанию 14). В базе до 10 последних курсов, поэтому следующие тесты и автосолвер начинают сразу.
   **NetAcad:** тексты модуля берутся из уже загруженного курса, без скачивания: при решении теста — текущий модуль, при пропуске материалов и в автосолвере — каждый открытый модуль, кнопкой **Загрузить этот курс** — все модули по оглавлению. В базу попадают страницы модуля, а для вопросов курса — их правильные ответы из данных курса.
2. Для каждой пачки из 10 вопросов выбираются самые близкие по словам фрагменты (поиск BM25); фрагменты из модуля, где стоит тест, и из предыдущего получают приоритет.
3. Модель получает около 24 000 символов материалов (≈6 тыс. токенов) с указанием: если курс утверждает что-то, отвечать как в курсе, даже если другие источники говорят иначе.

**База материалов.** «Настройки» → карточка «База материалов» → **Открыть базу** открывает отдельную страницу со всеми курсами, которые NSolver скачал:

- слева курсы с числом материалов, размером и датой загрузки;
- справа лекции, чтения и ваши заметки курса: поиск по тексту, просмотр и правка текста, переключатель «использовать» (выключенные материалы не попадают в запрос), удаление;
- **Добавить свой материал** — конспект, определения, ответы преподавателя: заметка уходит модели вместе с материалами курса;
- **Экспорт / Импорт JSON** — сохранить курс в файл или перенести его в другой браузер; **Удалить курс** — материалы скачаются заново при следующем тесте.

На странице курса Coursera или NetAcad кнопка **Загрузить этот курс** собирает материалы сразу, не дожидаясь теста. Курсы, которые вы правили, NSolver не заменяет и не удаляет сам; при повторной загрузке ваши заметки, правки и выключенные материалы сохраняются.

Это точнее, но каждый запрос дороже по токенам. Чтобы сэкономить, выключите переключатель — тогда модель отвечает по своим знаниям, как раньше.

## 5. Cisco NetAcad

На netacad.com NSolver читает вопросы как текст прямо со страницы курса: плеер `netacad.com/launch`, фреймы курса и Shadow DOM. Модели уходит только текст вопросов и вариантов, без скриншотов, поэтому это дёшево по токенам.

1. Откройте тест или страницу модуля с вопросами.
2. Запустите решение одним из способов:
   - плавающая кнопка **Решить** в правом нижнем углу страницы;
   - `Alt+K` (тот же хоткей, что у Quiz Solver; работает и внутри фреймов курса);
   - иконка NSolver → **Решить тест**.
3. NSolver отметит ответы на всех неотвеченных вопросах страницы и подсветит выбранное зелёной рамкой:

| Тип вопроса | Что делает NSolver |
|---|---|
| Один вариант (radio) | выбирает правильный |
| Несколько вариантов (checkbox) | отмечает все правильные и снимает лишние |
| Выпадающие списки (сопоставление, пропуски) | выбирает пункт в каждом списке |
| Текстовое поле | вписывает ответ |

4. Если вопрос отметить не удалось, карточка справа внизу покажет его номер и ответ: отметьте его сами.
5. **Проверьте ответы и нажмите Submit сами.** Уже отправленные (заблокированные) вопросы NSolver не трогает.

**Кнопка на странице** в карточке Cisco NetAcad (на главной вкладке, когда открыт NetAcad) показывает или прячет плавающую кнопку.

### Автосолвер квизов (Coursera и NetAcad)

Карточка **Автосолвер квизов** на главной вкладке. Кнопка **Пройти весь курс** (нажмите два раза: второе нажатие подтверждает, что квизы будут отправлены) проходит курс от первого модуля до последнего без вашего участия. Проходится только то, что идёт в оценку: практические задания на сдачу курса не влияют и пропускаются.

- **NetAcad:** открывает модули по оглавлению; в каждом засчитывает материалы и проходит квиз модуля: Start → ответ → Submit → подтверждение отправки. «Check Your Understanding» — практика, их автосолвер не трогает (решить их можно кнопкой **Решить**). Правильные ответы берутся из данных курса (точно и без токенов); вопросы без таких данных решает выбранная модель. Checkpoint Exam, Practice Final, Final Exam и опросы **не открываются**. Уже сданные квизы пропускаются.
- **Coursera:** по порядку курса открывает каждый тест с весом в оценке курса (Graded Assignment, graded quiz, module challenge и т.п.), нажимает Start / Resume, решает его моделью, отмечает Honor Code (и вписывает ваше имя, если Coursera его просит), отправляет и читает оценку. Practice Assignment, practice quiz, «Test your knowledge», уже сданные тесты и заблокированные элементы пропускаются.
- **Coursera, задания с взаимной проверкой** (переключатель **Задания с взаимной проверкой**, по умолчанию включён): NSolver читает инструкции, критерии и подсказки частей задания, модель пишет работу с опорой на материалы курса. На вкладке **My submission** NSolver вписывает **Project Title**, текстовые ответы, а для каждой части с файлом собирает свой документ (`Problem_1.docx`, `Problem_2.docx`… по заголовку части; PDF, если в тексте нет формул, таблиц и графиков) и загружает его через **Add File**. Графики, которые просит задание, NSolver рисует сам по формулам модели и вставляет в документ, таблицы становятся таблицами Word, нажимает **Submit** и подтверждает отправку (галочка и имя). Затем на вкладке **Peers to review** открывает работы однокурсников и проверяет столько, сколько требует курс («N left to complete»): модель читает текст работы и текст приложенных PDF / DOCX / PPTX, оценивает честно по рубрике (пустая или не по теме работа получает минимум) и пишет конкретный отзыв; NSolver отмечает варианты рубрики и нажимает **Submit Review**. Если часть задания требует ссылку или картинку, итог попросит сдать её вручную.
- **Coursera, programming assignments** (переключатель **Programming assignments**, по умолчанию включён): автосолвер открывает лабораторную (`…/lab`, Jupyter-ноутбук Coursera Labs). В ноутбуке NSolver находит ячейки с заданиями («YOUR CODE STARTS HERE», «# GRADED FUNCTION», «# Write your code here»), и модель пишет их код, не трогая остальные строки. Потом NSolver перезапускает ядро и прогоняет весь ноутбук. Ошибки и проваленные тесты он отдаёт модели на исправление (до двух раундов), сохраняет ноутбук и нажимает **Submit Assignment**. Задание засчитывается, когда Coursera отмечает его пройденным (обычно через 1–2 минуты). Одну лабораторную можно сделать без автосолвера: откройте её через «Launch Lab» и нажмите **Решить тест** или `Alt+K`.
- Одно задание с взаимной проверкой (в том числе практическое) можно сдать без автосолвера: откройте его и нажмите **Решить тест** или `Alt+K`. Coursera открывает каждый тест отдельной страницей: автосолвер продолжает работу после каждой загрузки.

**Если квиз не сдан** — выбор рядом с кнопкой: «Не пересдавать» (оставить вам), «2 пересдачи» или «3 пересдачи». На Coursera учитывайте лимит попыток курса (обычно 3 за 8 часов).

В конце карточка (NetAcad) или уведомление (Coursera) покажет итог и список несданных квизов с процентом. Повторное нажатие **Пройти весь курс** останавливает автосолвер (на NetAcad — после текущего модуля). Не переключайте вкладку, пока он работает.

### Пропуск материалов на NetAcad

Кнопка **Пропустить материалы** (или назначенный хоткей) проходит **весь курс**: NSolver сам открывает модули по оглавлению плеера (Module 1, Module 2, …) и в каждом отмечает пройденными все материалы — текст, видео, анимации, вкладки, таблицы, лабораторные — через движок курса, без прокрутки и просмотра. Курс из 22 модулей проходится примерно за минуту.

- Модули на 100% пропускаются.
- Checkpoint Exam, Final Exam, Practice Final, опросы и Packet Tracer Assessment **никогда не открываются**.
- Вопросы, модульные квизы и «Check Your Understanding» не трогаются: их решает кнопка **Решить**.
- Проценты модулей в оглавлении NetAcad пересчитывает, когда модуль открывают: после пропуска откройте модуль или обновите страницу.
- Не переключайте вкладку, пока идёт пропуск: браузер замораживает фоновые вкладки.

Если страница не похожа на плеер NetAcad (нет движка курса), NSolver проходит только то, что на экране: досматривает видео, прокручивает текст и открывает вкладки.

## 6. Пропуск материалов

1. Откройте любую страницу курса (`coursera.org/learn/<курс>/...`).
2. Нажмите **Пропустить материалы** во вкладке «Главная» или назначенный хоткей.
3. Уведомление показывает прогресс: `Naki: Отмечаю пройденными: 12 из 45…`
4. В конце появится итог: `Naki: Лекции: 30/30, материалы: 15/15. Диалоги и role play: 2/2.` Обновите страницу, чтобы увидеть прогресс курса.

NSolver сначала читает прогресс курса и трогает только то, что ещё не засчитано. **Dialogue** и **Role Play** (ИИ-диалоги Coursera Coach) засчитываются без переписки: сессия открывается и сразу завершается, Coursera считает такой элемент пройденным.

**Также обсуждения.** Если включить этот переключатель, NSolver оставит короткий шаблонный ответ в каждом ещё не пройденном обсуждении курса (с паузой 8 с между ответами). Ответы публикуются от вашего имени и видны другим студентам. По умолчанию выключено.

> У Coursera есть лимит на число постов на форуме для аккаунта. Если он исчерпан, Coursera отклоняет любые ответы — даже написанные вручную. NSolver тогда останавливает обсуждения и пишет об этом в итоге; повторите позже (обычно через несколько часов).

> Новые курсы Coursera могут блокировать автоматическую отметку. Тогда в итоге будет меньше отмеченных, чем всего.

## 7. Горячие клавиши

Назначаются в **Настройки → Горячие клавиши** и сразу работают на открытой странице курса Coursera и на NetAcad. В настройках браузера ничего менять не нужно.

| Действие | По умолчанию |
|---|---|
| Quiz Solver / решение на NetAcad | `Alt+K` |
| Пропустить материалы | не назначено |

- Нажмите на кнопку сочетания, затем нужные клавиши (например, `Alt+K`, `Ctrl+Shift+S` или просто `K`).
- `Esc` отменяет запись, `×` удаляет сочетание.
- Работает в любой раскладке: `Alt+K` срабатывает и при включённой русской раскладке.
- Сочетание без Ctrl/Alt (например, `K`) не срабатывает, пока курсор в поле ввода, чтобы не мешать печатать.
- Одно сочетание нельзя повесить на два действия: при повторе оно снимается со старого.

## 8. Язык интерфейса

Переключатель **RU / EN** в правом верхнем углу окна. Меняет язык окна, уведомлений на странице и сообщений об ошибках.

## Частые проблемы

| Проблема | Что делать |
|---|---|
| Статус «Откройте курс Coursera или Cisco NetAcad» | Откройте страницу курса (coursera.org/learn/… или netacad.com). Если она уже открыта, обновите вкладку. |
| «Вопросы теста не найдены» | Откройте попытку теста (Start/Resume) и обновите страницу. |
| Хоткей ничего не делает | Кликните по странице курса (фокус должен быть на ней). После переустановки расширения обновите вкладку. |
| «Неверный или неактивный API-ключ» | Проверьте ключ, баланс и доступ к выбранной модели у провайдера. |
| «Превышен лимит запросов (429)» | Подождите минуту или выберите другую модель. |
| «Ошибка … (400)» про модель | Нажмите ↻ и выберите модель из актуального списка. |
| Часть ответов не проставилась | В уведомлении указаны номера вопросов: ответьте на них вручную. |
| NetAcad: «На странице нет неотвеченных вопросов» | Откройте сам тест (страницу с вариантами ответов). Отправленные вопросы NSolver не трогает. |
| NetAcad: часть вопросов не отмечена | Номера и ответы показаны в карточке справа внизу: отметьте их сами. |
| NetAcad не распознаётся: кнопки «Решить» нет, статус «Откройте курс…» | Браузер работает со старой версией расширения. Нажмите ↻ у NSolver на странице расширений (`opera://extensions` в Opera / Opera GX), обновите вкладку NetAcad и проверьте версию внизу окна NSolver. Проверьте, что включена **Кнопка на странице**. |
| Материалы не отмечаются | Возможно, курс блокирует отметку. Откройте модуль курса, обновите страницу и попробуйте снова. |

Если проблема не решается: на странице Coursera или NetAcad нажмите `F12` → вкладка **Console**, отфильтруйте по `[Naki]` и приложите вывод к [issue](https://github.com/Naki-404/NSolver/issues).

## 10. Как это работает

```
Coursera page ──► interceptor.js ──► content.js ──► background.js ──► выбранный AI API
 (ответы API)     (MAIN world)      (вопросы,       (прокси, обход     (OctavAPI / Claude /
                                     ответы,         CORS)              ChatGPT / Gemini)
                                     хоткеи)
```

1. `interceptor.js` работает в контексте страницы и перехватывает два типа ответов Coursera: состояние попытки теста (`opname=QueryState`) и структуру курса (`onDemandCourseMaterials`).
2. `content.js` превращает их в список вопросов, строит запрос к модели, проставляет ответы в форму и показывает уведомления.
3. `background.js` отправляет запросы к AI API (со страницы Coursera это запрещено правилами CORS) и подключает расширение к уже открытым вкладкам после установки.
4. `model-provider.js` знает форматы всех четырёх API, проверяет и исправляет ответы модели.
5. На NetAcad `netacad.js` обходит страницу, фреймы курса того же домена и Shadow DOM, собирает вопросы с вариантами и отправляет их тексты модели через тот же прокси, а затем кликает по выбранным вариантам. Пропуск материалов работает там же: видео, прокрутка, открытие пунктов интерактивных блоков.
6. Настройки и ключи хранятся в `chrome.storage.local` вашего браузера.
